Редактирование карты

Выберите точку лифта или лестницы, переключите этаж и выберите соответствующую точку. Для изменения перехода нажмите на его обозначение в режиме выбора.

Загрузите граф для начала работы.

Карта

План этажа

Чтобы добавить точку, нажмите на карту. Чтобы добавить связь, выберите две точки. Для перехода между этажами выберите точку, переключите этаж и выберите вторую. В режиме выбора точки можно перемещать и редактировать.
